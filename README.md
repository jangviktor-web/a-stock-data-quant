## 📖 功能全景

| 命令 | 功能 | 类型 | 说明 |
|------|------|------|------|
| `analyze` | 📊 综合分析 | 核心 | 行情+指标+形态+策略信号+回测，一次出完整报告 |
| `compare` | 📈 多股对比 | 核心 | 并排对比多只股票技术面，内置实时行情 |
| `backtest` | 🧪 策略回测 | 核心 | 7种策略回测，支持止损/资金量/HTML输出 |
| `scan` | 📡 市场扫描 | 核心 | 全市场板块扫描，按策略信号排序 |
| `indicators` | 📉 技术指标 | 核心 | MA/MACD/RSI/KDJ/BOLL/CCI/ATR/OBV 等 20+ 指标 |
| `pattern` | 🔍 形态识别 | 核心 | W底、V型反转、杯柄、三重底、Zigzag |
| `fund` | 💰 资金面 | 核心 | 主力资金流向、大中小单分析 |
| `data` | 📋 行情数据 | 核心 | 原始K线数据，支持多周期 |
| `diagnose` | 🏥 综合诊断 | **新增** | 技术面+资金面+形态多维度评分 |
| `macro` | 📊 宏观数据 | **新增** | CPI/PPI 等宏观经济指标 |
| `hotspot` | 🔥 市场热点 | **新增** | 人气榜+概念板块热点 |
| `realtime` | 📡 实时行情 | **新增** | 腾讯/东方财富秒级行情 |
| `search` | 🔍 股票搜索 | **新增** | 关键词搜索股票代码 |
| `em-diagnose` | 🤖 AI诊断 | **新增** | 东方财富妙想AI综合分析 |
| `em-pick` | 🤖 AI选股 | **新增** | 自然语言条件选股 |
| `em-ask` | 🤖 AI问答 | **新增** | 任意金融问题 |
| `em-news` | 🤖 AI资讯 | **新增** | 实时财经新闻搜索 |
| `em-fund` | 🤖 AI基金 | **新增** | 基金诊断+持仓分析 |
| `cache` | 💾 缓存管理 | **新增** | 查看/清理数据缓存 |
| `list` | 📝 列表 | 辅助 | 查看所有可用指标/策略/形态 |

## 📅 K线周期

| 周期 | 代码 | 说明 |
|------|------|------|
| 日线 | `1d` | 默认，适合中长线分析 |
| 周线 | `1w` | 中期趋势 |
